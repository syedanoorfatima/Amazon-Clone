# 🛒 Amazon Clone

A modern, responsive Amazon-inspired e-commerce website built using
HTML5, CSS3, and JavaScript.

## 🚀 Features

- Responsive Amazon-style UI
- Product search
- Product categories
- Today's Deals
- Add to Cart
- Quantity management
- Remove from Cart
- Dynamic cart total
- LocalStorage cart persistence
- Hero image slider
- Wishlist UI
- Notifications
- Responsive navigation
- Mobile-friendly design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- LocalStorage API

## 🎯 Purpose

This project was created to strengthen my frontend development skills
and understand how real-world e-commerce interfaces work.
